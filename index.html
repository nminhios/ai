Cài đặt Groq API

Trang này gọi Groq API trực tiếp từ trình duyệt. API key đã được lấy từ file HTML cũ. Bạn có thể thay key mới tại đây hoặc sửa giá trị GROQ_API_KEY trong file HTML.

Model mặc định: qwen/qwen3.8-27b (hỗ trợ ảnh). Khóa nhập tại đây chỉ lưu trong bộ nhớ trình duyệt hiện tại.

⚠️ API key được nhúng trực tiếp có thể bị người khác lấy qua mã nguồn/DevTools. Vì key trong file gốc đã lộ, hãy thu hồi key đó và tạo key mới; đây là cách gọi trực tiếp theo yêu cầu của bạn, không phải phương án an toàn để công khai.
